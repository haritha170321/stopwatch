Object-Oriented Programming (OOP) Architecture

Academic Demonstration

This web application mirrors the architectural concepts implemented in the companion Java Swing desktop application:

🛡️

Encapsulation

Timing state, start timestamps, and accumulated duration are encapsulated within dedicated classes/modules, with controlled accessors preventing direct external tampering.

🧩

Abstraction

Clock interfaces expose high-level operations (start, pause, resume, recordLap) while abstracting the monotonic hardware time synchronization details.

⚡

High Precision Timing

Calculates elapsed duration via performance.now() monotonic timestamps rather than counting tick intervals, avoiding browser background throttling drift.

📊

Composition & Analytics

Stopwatch contains an unmodifiable record of Lap entities, enabling automatic minimum/maximum split evaluation and CSV data transformation.

Keyboard Shortcuts

Control the stopwatch quickly with these hotkeys:

  • Space Start, Pause, or Resume stopwatch
  • L Record Lap split time
  • N Record Lap with custom note
  • R Reset stopwatch (prompts if laps exist)
  • C Clear recorded laps
  • E Export laps to CSV
  • T Toggle Light / Dark mode
  • H Open Session History
  • ? Toggle this help dialog
  • Esc Close modal
